# 灵灵 · 前端「高级感」设计简报（第 1 轮：只做首页）

> 派给 dsh 执行。目标是「点开第一眼就像一份做得讲究的刊物」，不是「像某个 SaaS 落地页」。
> 这份简报的禁止清单和硬约束优先于任何审美自由。

---

## 0 · 一句话

**用排版和留白撑起高级感，而不是用装饰。** 高级 = 克制 + 细节密度 + 一致的节奏；
廉价 = 渐变、发光、玻璃、超过两级的阴影、圆角气泡感。

---

## 1 · 硬约束（违反即返工）

1. **零依赖、零构建**：不引任何外部 CSS/JS/字体/图标/图片。所有纹理必须内联（SVG data URI 也算内联）。
2. **零外部请求**：页面加载后 `performance.getEntriesByType('resource')` 里不得出现本站之外的 URL。
3. **保留契约**：`data-shell="cta"`、`data-shell="ilist"`、`data-shell="pnav"`、`data-shell="judgment"` 这些占位**必须保留**且行为不变；`exp/episodes.js` 的字段名不得改动。
4. **保留交互与功能**：不得删除任何现有入口（机会卡 / 全部卡片 / 旧版归档 / GitHub 链接）。
5. **可用性**：375px 无横向溢出；所有可点元素触控高度 ≥44px；正文对比度 ≥4.5:1；`prefers-reduced-motion` 下所有动效归零。
6. **可降级**：`file://` 双击打开要正常（不要用 fetch / ES module）。
7. **文案**：不得改写首页的既有文案语义（可以调整断行、大小写、字距）。口径是「每周一期」。

---

## 2 · 视觉语言（执行细则）

### 2.1 字体
- 不引外部字体。展示层用系统衬线（`Georgia, 'Times New Roman', 'Songti SC', 'SimSun', serif`），正文用系统无衬线。
- 展示字：`letter-spacing: -0.02em ~ -0.03em`，`line-height: 1.05 ~ 1.15`。
- 标签/日期/编号：无衬线全大写（中文不转），`letter-spacing: .14em`，字号 10.5–12px。
- 所有数字加 `font-variant-numeric: tabular-nums`。

### 2.2 字号阶梯（用 clamp，不要写死一堆 px）
```
展示 1：clamp(40px, 7vw, 68px)     ← 首屏主标题
展示 2：clamp(26px, 3.4vw, 34px)   ← 次标题 / 期号大字
小标：  11–12px，全大写，字距 .14em
正文：  15.5–16.5px，行高 1.7
脚注：  12–12.5px，行高 1.6
```

### 2.3 网格与节奏
- 最大宽 **1180px**，左右留白 20px（移动）/ 32px（桌面）。
- 垂直节奏以 **8px** 为基准：区块间距只允许 8 的倍数（24/32/48/64/96）。
- 12 栏网格；首页目录区在桌面两栏（左：期号；右：标题+标签），移动端堆叠。

### 2.4 颜色
- 底色：去饱和的纸色（保持现有 `#FAF8F3` 系），不要纯白。
- 墨色：近黑不纯黑（`#242220` 一类）。
- **每页只允许 1 个强调色**（首页用现有琥珀 `#8A6508` 系；期卡自身主题色只出现在序号/标签/左侧色条）。
- 禁止：渐变按钮、彩色发光、玻璃拟态、多色强调。

### 2.5 线条、圆角、阴影
- 主用 **1px 半透明 hairline**（`rgba(44,42,38,.14)`），不要粗黑边。
- 圆角：卡片 **≤6px**；按钮 4px；不要 16px 的「App 圆角」。
- 阴影：最多一级，且极淡（如 `0 1px 0 rgba(44,42,38,.06)`）。禁止多层堆叠阴影。

### 2.6 纹理（可选，最多一处）
- 用内联 SVG `feTurbulence` 做极细噪点，`opacity ≤ .04`；或 1px 网格线 `opacity ≤ .05`。
- 不得使用外部图片。

### 2.7 动效
- 时长 180–420ms，缓动 `cubic-bezier(.2,.7,.2,1)`。
- 只允许：进场 `opacity + translateY(8px)`（可 40ms 级联）、hover 位移 1–2px、下划线生长、数字滚动。
- 禁止：视差、弹跳、旋转、无限循环动画、超过 600ms 的动画。

## 3 · 首页具体要求

### 3.1 首屏（封面感）
- 主标题按「展示 1」尺寸，两行以内；下面一行 15.5px 的说明，最大 34em。
- 右上角一列小字：`VOL. 06 / 2026.10`、状态行（示例数据 · 规则模拟）。
- 首屏底部一条 1px 横线，把「封面」和「目录」分开。

### 3.2 最新一期（把黑按钮改成条目）
- 不再是一个纯黑圆角按钮。做成一条**通栏条目**：
  - 左：`最新一期` 小标 + 期号大字（如 `06`）
  - 中：标题（衬线 26–30px）
  - 右：`直接开玩 →`
- hover：整条右侧箭头位移 4px + 下划线生长；**不要**背景整块变色。

### 3.3 往期实验（六条目录，不是六张同款卡）
- 每条一行（桌面）：
  - 左列：期号（衬线大字，60px 左右，`06` 这种两位数）
  - 中列：标题（16.5px） + 一行 meta（日期 · 形态）
  - 右列：主题标签（小写/全大写）、`进入 →`
- 行与行之间用 1px hairline 分隔；**不要**每行都有卡片边框和阴影。
- 每条左侧 2px 色条用该期主题色；hover 时色条变成 6px，标题左移 2px。
- 移动端：期号缩到 26px，与标题同一行。

### 3.4 页脚（版权页感）
- 细线分隔，三栏小字：左「灵灵 · 每周实验」/ 中「旧版界面 v1 v2 v3」/ 右「GitHub ↗ · 机会卡」。
- 字号 12px，行高 1.9，全部用 `--ink-3` 灰。

## 5 · 自检（交付前必须自己跑一遍，并把结果写进回复）

1. 无外部请求：用浏览器打开 `index.html`，`performance.getEntriesByType('resource')` 过滤掉本站/`file:` 后为空。
2. 375 / 768 / 1280 三档：`document.documentElement.scrollWidth <= innerWidth`。
3. 零 JS 报错：监听 `window.onerror` 与 `unhandledrejection`，为空。
4. 六条目录都在、顺序 01→06、链接指向 `exp/p1..p6.html`。
5. 最新一期条目指向 `exp/p6.html`，文案含「第 06 期」。
6. 所有可点元素 `getBoundingClientRect().height >= 44`。
7. `prefers-reduced-motion: reduce` 下动画时长为 0。

## 6 · 禁止清单（出现任何一条即判不合格）

- ❌ 毛玻璃 / `backdrop-filter` / 半透明模糊卡片
- ❌ 彩色渐变（`linear-gradient` 仅允许用于 ≤2% 明度的纸面提亮，且不作为按钮背景）
- ❌ `box-shadow` 发光（`0 0 Npx` 带颜色）
- ❌ emoji 当图标（✦ ★ ▶ 之类字符可以用，emoji 不行）
- ❌ 外链字体 / 图标库 / CDN
- ❌ 圆角 > 8px 的卡片
- ❌ 同时出现 3 个以上强调色
- ❌ 动画 > 600ms 或无限循环
