## 三、原型合格标准（每一期都必须满足，逐条自检）

一条硬线：**合格标准是"体验到一个想法"，不是"生成了一份 HTML"。**

1. **一个具体角色 + 一项小任务**，30～60 秒能走完
2. **至少两种输入或选择**，产生**有意义的不同结果**（不是换文案，是结果真的不同）
3. **有一个值得再玩一次的变量**（换条件／换顺序／换对象）
4. **明确标注**使用的是「示例数据 / 规则模拟 / 真实 AI」——本轮一律标注 **示例数据 · 规则模拟**
5. **轮换交互形式**：三期分别用 **拖拽 / 参数调整 / 分支选择**，不得都是"输入框＋生成报告"
6. **零依赖**：单文件 HTML+CSS+JS，无 CDN、无构建、无框架、无外部请求
7. **可离线打开**：双击文件即完整可玩
8. **移动优先响应式**：375px 起，不出现横向滚动
9. **无障碍**：全部功能键盘可完成（Tab/Enter/方向键）、触控目标 ≥44×44px、`prefers-reduced-motion` 下关闭非必要动画
10. **无密钥、无后端调用**：页面里不得出现任何 API key，不得请求 `/api/*`

## 五、主入口页 `frontend/index.html` 的结构

顺序**必须**照此（来自顾问建议）：

```
① 刊头      期号 · 日期 · 主题一句话 · 「本期实验」标记
② 一句话场景 讲清楚"你是谁、要干什么"，不看分析就能上手
③ 直接开玩   原型以 <iframe sandbox="allow-scripts"> 嵌入，固定高度容器（移动端 ≥560px）
             ＋「在新窗口打开本期」备用链接（file:// 下 iframe 可能被拦，此时必须仍有出路）
④ 灵感来源   展示：原作者/原始信号实际是什么（真实标题＋原文链接）
             ＋ 分开写明「灵灵据此延伸的设想」
⑤ 数据说明   显式标注「示例数据 · 规则模拟」，一句话说明本轮未接入真实模型
⑥ 翻页       上一期 / 下一期；默认显示最新一期（03）
             用 location.hash（#01/#02/#03）表示当前期，可直接分享
⑦ 页脚       旧版入口链接 → /cards.html
```

**隔离要求**：原型一律走 `iframe sandbox="allow-scripts"`，**不得**把原型脚本内联进主页面执行。
禁止在页面任何位置出现密钥。
