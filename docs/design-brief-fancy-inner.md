# 灵灵 · 内页「高级刊物感」简报（第 2 轮：p1–p6）

> 第 1 轮已把首页升级完成（`docs/design-brief-fancy.md`）。这一轮把六期内页抬到同一档。
> **核心区别：内页不能丢各自的主题形态**——01 是档案台、02 是旧机房、03 是告警台、04 是校准台、05 是审稿页、06 是翻面。
> 这轮做的是「同一套刊物级排版纪律」，不是把它们改成同一个样子。

---

## 1 · 硬约束（违反即返工）

1. **零依赖零构建**：不引外部 CSS/JS/字体/图标/图片；纹理只能内联（SVG data URI）。
2. **零外部请求**：`performance.getEntriesByType('resource')` 过滤本站/`data:`/`file:` 后必须为空（页脚的「原文链接」是 `<a href>`，不算请求）。
3. **契约不能破**：`data-shell="pnav"`（上下两条）、`data-shell="judgment"` 必须保留，且仍由 `episodes.js` 渲染；`episodes.js` 字段名不得改。
4. **交互不能丢**（这是硬线，逐页列在 §4）。
5. **可用性**：375/768/1280 无横向溢出；可点元素 ≥44px；正文对比度 ≥4.5:1；`prefers-reduced-motion` 下所有动效归零。
6. **`file://` 可用**：不得用 `fetch` 加载数据、不得用 ES module。
7. **文案语义不变**：可以调断行、字距、大小写；不得改写句意，不得删除"示例数据 · 规则模拟"的声明。

---

## 2 · 刊物级排版纪律（六页共用）

### 2.1 字号阶梯
```
页面主标题   clamp(26px, 3.4vw, 34px)   字距 -0.02em  行高 1.15
区块标题     17–19px                    字距 -0.01em
正文         15.5–16.5px                行高 1.7
次要说明     13–13.5px                  行高 1.65
标签/脚注    10.5–12px  全大写  字距 .14em
```
- 所有数字 `font-variant-numeric: tabular-nums`。
- 正文行宽 ≤ 38em。

### 2.2 间距与网格
- 内容版心 **1080px**，左右 20/32px。
- 垂直节奏只用 8 的倍数：**24 / 32 / 48 / 64**。
- 区块之间用 1px hairline 或 32–48px 留白分隔，**不要**用「卡片套卡片」。

### 2.3 线条 / 圆角 / 阴影
- 主用 1px 半透明细线；强调用 2px 实色（如左侧色条）。
- 圆角 **≤6px**；按钮 4px。
- 阴影最多一级、极淡；**禁止**多层堆叠与发光。

### 2.4 颜色
- 底色沿用各页主题纸色（不要统一成首页色）。
- **每页只允许 1 个强调色**（就是该页现有的主题色），其余用墨色三阶。
- 禁止渐变按钮、彩色发光、毛玻璃。

### 2.5 控件
- 按钮/选项/通道行：最小高 44px，1px 边 + 文字表达状态，不靠大面积纯色块。
- hover/active 只允许：1–2px 位移、边框/文字色变化、下划线生长、左侧色条加宽。
- 焦点态必须可见（`outline: 2px`）。

### 2.6 动效
- 180–420ms，`cubic-bezier(.2,.7,.2,1)`。
- 只允许：进场 `opacity + translateY(8px)`（可 40ms 级联）、hover 位移、进度条宽度、数字变化。
- 禁止：视差、弹跳、旋转、无限循环、>600ms。

## 3 · 站点外壳（六页必须一致）

- 顶栏 `.lnav`：结构与样式**逐字保留**，不要改。
- 期号条 `.pnav`：结构保留；只允许调间距/字号/当前期样式（用该页主题色）。
- 底部的「这一期的灵感来源」与页脚：统一成 12.5px/1.78 的行距、1px 分隔线、链接样式与首页一致（`--ink` 下划线、hover 变主题色）。
- 顶部刊头（brand / 期号 / 日期 / 示例数据标签）：对齐到 8px 节奏，日期与期号用 tabular-nums。

## 4 · 每页要保留的形态与交互（不可改）

| 页 | 主题形态 | 必须仍然可用 |
|---|---|---|
| `p1.html` | 牛皮纸档案台：申请表、三个文件盘、「已归档」章 | 卡片可拖动/点选、放进三个盘、提交、重玩 |
| `p2.html` | 珐琅灰绿旧机房：刻度滑块、LED 读数、仪表箱 | 三个参数可调、结论实时变、对照/固定 |
| `p3.html` | 深色告警台：告警条、按键式选项、日志 | 每步分支可点、进度推进、结局与复盘 |
| `p4.html` | 校准台：六条通道、贯穿阈值线、AUTO/ASK 灯 | 阈值滑块可拖、状态与计数实时变 |
| `p5.html` | 审稿页：左稿件（行号/diff）右页边批注 | 每份稿选一支笔、批注出现、四份选完出结论、重置 |
| `p6.html` | 翻面：正面/背面、接单票据盖章 | 六个技能可切、三行改写刷新、接三单解锁 |

## 5 · 每页的「做精」重点（只做这些，别扩散）

- **p1**：申请表字段对齐（编号/团队/请求/影响范围行标签右对齐）；文件盘做出「托盘 + 标签页」的层次；提交后的结果做成**归档清单**（细线表格，不是卡片墙）。
- **p2**：面板顶部加一条铭牌（型号 / 参数 / 状态）；三个滑块做出刻度齿与指针；右侧结论做成仪表箱（等宽读数 + 1px 框），数字右对齐。
- **p3**：告警条加等宽时间戳列；日志行等宽、左对齐；按键选项做出键帽的下沿（1px 硬阴影，按下位移 2px）；进度条改成**分段刻度**而不是纯色条。
- **p4**：读数窗与刻度的对齐；六个通道行的高度统一为 8 的倍数；AUTO/ASK 用 1px 边 + 文字，别用大色块。
- **p5**：稿件页边距与行号列的对齐；批注加一条 1px 引线指向行号；四份稿的垂直节奏一致。
- **p6**：正面/背面的纸张层次（背面比正面"实"一档）；票据的虚线、盖章角度、金额用等宽。

## 6 · 自检（每页都跑，交付时报数字）

1. 外部请求 0（过滤本站/`data:`/`file:`）。
2. 375 / 768 / 1280：`scrollWidth <= innerWidth`。
3. `window.onerror` 与 `unhandledrejection` 均 0 条。
4. 该页交互按 §4 能用（用脚本点一遍，报结果）。
5. 所有 `a/button/input` 可见元素 `height >= 44`（滑块轨道除外，但滑块容器 ≥44）。
6. `prefers-reduced-motion: reduce` 下 `animation-duration` 与 `transition-duration` 均为 0s。
7. `file://` 打开无报错、`pnav` 与 `judgment` 正常。

---

## 7 · 禁止清单（出现即返工）

- ❌ 毛玻璃 / `backdrop-filter`
- ❌ 彩色渐变（纸面 ≤2% 提亮除外）
- ❌ 发光阴影（`0 0 Npx` 带颜色）
- ❌ emoji 当图标
- ❌ 外链字体/图标/CDN
- ❌ 圆角 > 8px
- ❌ 3 个以上强调色
- ❌ 动画 > 600ms 或无限循环
- ❌ 把六页改成同一个样子（主题形态必须保留）
