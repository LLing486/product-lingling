一句话场景WHAT YOU DO

角色 · 接手老系统的工程师参数调整

你是刚接手一套 2011 年老系统的工程师：代码没人敢动、文档早就丢了、原班人马一个都不在。你要拧三个旋钮 —— 上下文预算、代码年代跨度、提问粒度 —— 看看这套「考古方案」到底能回答什么、答不了什么，以及要花掉多少钱。

  1. 先选这套遗留系统长什么样（单体 Java / 存储过程 / 前端老框架）。
  2. 拧三个参数，每动一下都能看到输出跟着变。
  3. 对着「能答 / 遗漏 / 成本」三块结果，找一个你敢签字交差的组合。

一句话场景WHAT YOU DO

角色 · 凌晨值班工程师分支选择

凌晨 2:33，告警响了。你是当班工程师，面前有 4 个决策点，每一步都得选一次：让 AI 全权接管、人工确认后执行、还是升级上报。不同选法通向不同结局 —— 服务恢复、误操作把故障扩大、或者延迟恢复但零风险 —— 走完会给你一份属于这条路径的复盘。

  1. 先选今晚的开局（单点故障 / 连锁告警 / 灰度发布中）。
  2. 每个决策点三选一，选完立刻看见后果。
  3. 走到结局，读复盘：看看你是在哪一步把风险放大的。
